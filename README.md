# 🌊 大学课程资料库

欢迎靠岸！亚托莉今天也在值班。大学期间的课件、笔记、作业、实验代码和复习资料，都按课程收好啦。(｀・ω・´)ゞ

> [!IMPORTANT]
> **下载资料包**
>
> - **按课程下载**时，先打开对应课程目录里的 `.rar` 或 `.zip` 资料包，再点文件页右上方的 **Download raw file**（下载图标）。两份 **Git LFS 资料包**也可直接进入文件页下载，见 [信息论资料包.zip](./信息论/信息论资料包.zip) 和 [矩阵理论.rar](./矩阵理论/矩阵理论.rar)。
> - **整库下载**请在仓库首页选择 **Code → Download ZIP**。解开外层 ZIP 后，到各课程目录打开资料包。
> - **Git 克隆后下载**需要安装 [Git LFS](https://git-lfs.com/)，然后在本地仓库目录运行 `git lfs pull` 获取完整的 LFS 资料包。
