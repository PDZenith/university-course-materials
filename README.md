# 大学课程资料库

集中归档大学期间的课程资料，方便查找学习记录、回顾课程内容和准备复习。每门课程使用一个以课程名命名的目录。

> [!IMPORTANT]
> **下载资料包请先进入下方对应的课程目录，再打开压缩包文件，在文件页点击下载。**
>
> 矩阵理论和最优化算法及其应用的资料包为 **RAR**，信息论的资料包为 **ZIP**。
>
> **整库下载**可在仓库首页选择 **Code → Download ZIP**。解开外层 ZIP 后，进入对应课程目录即可打开资料包。

## 归档方式

课件、课堂笔记、作业、实验代码和复习资料放入对应的课程目录。资料较多时，再按类型、章节或周次建立子目录。同一门课跨学期开设时，可在课程目录下按学期区分。

工科数学分析、信号与系统、概率论与数理统计的目录已建立，待补充资料。

标注为 Git LFS 的压缩包可在 GitHub 文件页下载。用 Git 克隆仓库后，可运行 `git lfs pull` 获取这些压缩包。
