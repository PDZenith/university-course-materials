# 信息论

下载 [信息论资料包.zip](./信息论资料包.zip)（Git LFS）。压缩包含九份专题讲义的 Markdown 和 PDF 版本，以及不同教学班的课件、练习和作业。

## 专题讲义

| 编号 | 内容 |
| --- | --- |
| 01–02 | 香农三定律、信源信道分离定理、网络信息论定理证明 |
| 03–05 | 熵、互信息与 Markov 信源，信道容量，率失真函数与试验信道 |
| 06–09 | Fano 码、Huffman 码、线性分组码、Hamming 码、LDPC 码、卷积码与 13 折线 A 律编码 |

## 课件和练习

- `陈伟健班/` 收录课程练习、部分参考解答和作业。
- `高林班课程资料/` 收录 PPT 课件、习题、复习材料，以及复习题题干和解答的转写稿。
- `高林班作业/` 收录随堂测试材料。

解压后可先打开包内 `README.md` 定位专题讲义，再按需要查阅课件或习题。
